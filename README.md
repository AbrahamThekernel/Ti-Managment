# 1. Descripción del proyecto

El proyecto **Equipo de Soporte de CGTI** consiste en el desarrollo de una solución informática orientada a mejorar la administración, organización y seguimiento de las solicitudes de soporte técnico dentro de un área de Tecnologías de la Información.

La solución busca facilitar el registro de problemas, solicitudes e incidencias reportadas por los usuarios, permitiendo que el personal encargado pueda consultar la información, dar seguimiento a los casos y mantener un registro organizado de las actividades realizadas.

El sistema surge a partir de una problemática real relacionada con la dificultad de administrar solicitudes de soporte cuando la información se encuentra distribuida entre diferentes medios de comunicación o registros.

---

# 2. Problema real detectado

En un área de soporte de Tecnologías de la Información se reciben constantemente solicitudes relacionadas con problemas de hardware, software, conectividad, cuentas de usuario, sistemas institucionales y otros servicios tecnológicos.

Cuando estas solicitudes son administradas mediante métodos poco estructurados, pueden presentarse diferentes problemas:

- Solicitudes que no reciben seguimiento adecuado.
- Pérdida de información relacionada con una incidencia.
- Duplicidad de reportes.
- Dificultad para conocer el estado actual de una solicitud.
- Falta de información histórica sobre problemas anteriores.
- Dificultad para determinar qué persona está atendiendo cada caso.
- Falta de organización en las prioridades de atención.
- Dificultad para obtener estadísticas sobre las solicitudes recibidas y solucionadas.

Esta situación puede provocar retrasos en la atención de los usuarios y dificultar la administración del trabajo realizado por el equipo de soporte.

Por esta razón se propone una solución que permita centralizar y organizar la información relacionada con las solicitudes de soporte.

---

# 3. Justificación

La implementación de un sistema para la gestión de soporte permite mejorar la organización de las actividades realizadas por el personal de Tecnologías de la Información.

Al contar con un registro estructurado de las solicitudes, es posible consultar información importante sobre cada caso, conocer su estado, identificar responsables y conservar antecedentes que pueden ser útiles para solucionar problemas similares en el futuro.

Además, una herramienta de este tipo permite mejorar la trazabilidad de las solicitudes y facilita la generación de información que puede utilizarse para evaluar el funcionamiento del área de soporte.

---

# 4. Objetivo general

Desarrollar un sistema que permita registrar, administrar, consultar y dar seguimiento a las solicitudes de soporte técnico, proporcionando una herramienta organizada para mejorar el control de las incidencias atendidas por el área de Tecnologías de la Información.

---
